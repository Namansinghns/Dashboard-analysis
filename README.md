Dashboard-analysis

This project is part of a collection of data visualization projects developed using Looker Studio and Power BI and excel dashboard. It focuses on transforming raw data into interactive dashboards and visual reports to support data-driven decision-making. And attached all dashboard png format file for easy to find.

Objectives

Convert raw data into meaningful dashboards
Identify trends and patterns through visualization
Enable easy comparison across categories and metrics
Improve business understanding through interactive reports

Key Tasks Performed

Data cleaning and transformation using Power Query
Data modeling and relationship building
Creation of calculated columns and measures (DAX)
Dashboard design and layout structuring
Use of filters, slicers, and drill-down features

Dashboard Features

Interactive filters and slicers
KPI cards for key metrics
Trend analysis using line charts
Category-wise comparison using bar charts
Summary insights using visual elements
